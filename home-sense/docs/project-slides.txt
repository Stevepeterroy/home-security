ABSTRACT
Traditional home security systems such as CCTV and PIR sensors suffer
from privacy concerns, limited coverage, and high false alarm rates.
The proposed system combines WiFi Channel State Information (CSI) and
mmWave radar to detect human presence without using cameras.
ESP32 collects WiFi CSI data while the mmWave radar provides range,
angle, and velocity information.
Artificial Intelligence is used to classify human activities such as walking,
standing, intrusion, and fall detection.
The system generates real-time alerts through IoT and improves detection
accuracy by fusing WiFi CSI and mmWave sensing.

INTRODUCTION
Modern home security requires intelligent monitoring while preserving user
privacy.
WiFi CSI enables contactless sensing by analyzing changes in wireless
signal propagation caused by human movement.
mmWave radar accurately measures human position, velocity, and
movement even in low-light conditions.
This work integrates WiFi CSI, mmWave radar, and AI to provide an
efficient smart home security solution.

WiMUAR: Wi-Fi CSI Activity RecognitionReference:[1]
Problem Statement
When several people move at once, their activities produce overlapping changes
in Wi-Fi CSI. The paper aims to recognize each person’s activity from these
complex signals.
Technology Used
Wi-Fi CSI, CSI scaling and dynamic component separation, multi-scale dilated
CNN, attention-enhanced bidirectional GRU, and online knowledge distillation.
Advantages
Recognizes activities in multi-person settings.
Learns both CSI patterns and how they change over time.
Uses Wi-Fi signals without requiring a camera.
Disadvantages for Our Project
Does not include mmWave radar or Wi-Fi–radar fusion.
Its full model is more complex than our planned single-person baseline.

Wi-Fi CSI-Based HAR and Indoor Localization
Reference:[2] I
Problem Statement
Irregular Wi-Fi CSI sampling caused by unstable packet transmission
reduces activity recognition and indoor localization accuracy.
The paper proposes a sampling irregularity mitigation framework to
improve reliable real-time CSI sensing.
Technology Used
NeuralCDE, dual-stream learning(Temporal,Channel), Cross
Attention,Dual-task learning.
Advantages
Improves recognition and localization accuracy.
Reduces the effect of irregular CSI sampling.
Robust under unstable Wi-Fi conditions.

Spatial-Temporal Point MambaReference:[4]
Problem Statement
Existing activity recognition models struggle to efficiently process sparse
mmWave radar point clouds. The paper introduces the Spatial-Temporal
Point Mamba model for accurate activity recognition.
Technology Used
mmWave Radar Point Clouds, Mamba Network
Advantages
Captures spatial and temporal information effectively.
High recognition accuracy.
Efficient point cloud processing.
Suitable for real-time applications.
Disadvantages
Requires mmWave radar hardware.
Model training requires large datasets.

Human Activity Recognition via Wi-Fi and Inertial Sensors With Machine
Learning
Reference:[5]
PROBLEM STATEMENT
Human activity recognition using a single sensing modality often suffers
from limited accuracy and robustness due to environmental variations and
sensor limitations. The paper proposes combining Wi-Fi CSI and IMU
sensor data to improve activity recognition performance.
TECHNOLOGY USED
Wi-Fi Channel State Information (CSI), Inertial Measurement Unit (IMU),
Machine Learning-(SVM,MLP,Decision Tree,Random Forest,Logistic
Regression,kNN)
ADVANTAGES:
Improves activity recognition accuracy through sensor’s data fusion.
Low-cost implementation using existing Wi-Fi infrastructure.
DISADVANTAGES:
Requires wearable IMU sensors in addition to Wi-Fi sensing.
Less suitable for completely contactless monitoring.

PROPOSED SYSTEM AND DESIGN
The proposed system integrates WiFi CSI sensing with mmWave radar for
intelligent indoor security.
ESP32 collects CSI data while the mmWave radar captures precise human
movement information.
Signal processing removes noise.
Artificial Intelligence performs activity recognition and intrusion
classification.
Fusion of datas from WiFi CSI and mmWave data to improve detection
accuracy.
The system sends instant alerts to homeowners through IoT platforms.

Feasibility Study
Feasibility study evaluates the practicality of implementing the proposed smart
home security system.
Technical Feasibility:
ESP32, WiFi routers, and mmWave radar sensors are commercially
available.
Open-source AI frameworks such as TensorFlow and PyTorch support
activity recognition.
Operational Feasibility:
Easy installation without major infrastructure changes.
Fully automated operation with minimal user intervention.
Suitable for homes, offices, and elderly monitoring.
Economic Feasibility:
Lower installation cost compared to advanced CCTV systems.
Low maintenance and scalable for multiple rooms.
